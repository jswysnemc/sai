# 有界正文转换

`buffer:document(options?)` 将当前回调的原始缓冲转换为文本摘录，返回转换后的完整字符数量。它适用于网络或文件正文大于普通 Lua 文本接口上限，但最终只需交付有限摘录的场景；不需要把完整正文复制进 Lua。

```lua
local response = sai.binary.request({url = url, max_bytes = 262144})
local ok, document = pcall(response.body.document, response.body, {
    mode = "html_markdown", max_chars = 2000, timeout_ms = 3000,
})
response.body:close()
assert(ok, document)
return document
```

输入来源仍需原来的网络或文件授权。转换本身是当前回调内的纯内存工作，允许只读工具和事件，不授予任何 I/O 或写入权限。初始化不能创建业务缓冲，已关闭或跨回调保存的句柄也不能转换。

## 参数与结果

| 选项 | 类型及默认值 | 行为 |
| --- | --- | --- |
| `mode` | `raw`、`html_text`、`html_markdown`，默认 `raw` | 原文、HTML 转纯文本、HTML 转 Markdown |
| `max_chars` | 正整数，默认 24000 | 返回至多这些 Unicode 标量字符；0、负数、分数及数字字符串拒绝 |
| `width` | 整数 20–200，默认 120 | HTML 纯文本换行宽度；其他模式接受但不使用 |
| `timeout_ms` | 可选正整数毫秒，默认 `limits.binary_timeout_ms` | 收窄到该上限；排队时间计入期限，回调总期限仍有效 |

未知字段和错误类型直接失败。接口不推断 MIME 类型，也不使用 HTTP charset；输入始终按 UTF-8 替换解码，无效字节变为 U+FFFD。需要其他字符集时使用文本 HTTP 或显式解码接口。HTML 选择、状态处理和业务提示由插件负责。

返回 `{text: string, total_chars: integer, truncated: boolean}`。`total_chars` 计算整个转换结果，`truncated` 表示摘录字符数少于总数，`text` 不包含附加截断提示。字符不是 UTF-8 字节或用户可见字素簇，组合字符会分别计数。

`html_text` 使用转换专用的 `html2text 0.13.6`，长单词换行按位置前进，避免旧版反复扫描和复制剩余长词；转换库错误作为 Lua 异常返回。Markdown 使用 `html2md`，相对链接按输入保留。此接口是新契约；旧 `sai.text.html_to_text` 继续使用既有转换器，部分复杂 HTML 的排版可能不同。

## 资源与生命周期

原始输入最多 8 MiB，HTML 转换中间结果最多 16 MiB。最终完整 JSON 结果，包括字段名、字符转义和元数据，必须满足 `limits.output_bytes`；超出时失败，不在字符上限之外再静默裁剪。所有限制同时成立，不保证任意 8 MiB HTML 都能在所选预算下完成。

转换开始前从 VM 二进制额度预留工作空间。设输入为 `N` 字节、输出预算为 `O` 字节，额外预留如下；已存在的输入缓冲另行计费：

| 模式 | 额外预留 |
| --- | --- |
| `raw` | `3N + O + 64 KiB` |
| 两种 HTML 模式 | `8N + 16 MiB + O + 64 KiB` |

这是调用调度和并发占用的估算，不是 HTML 库分配器或整个进程的硬内存上限。复杂 DOM、表格和第三方库内部数据可能消耗更多内存。额度不足时先失败；关闭无用缓冲可释放空间，但不提高硬上限。

解码和转换按输入字节扣除共用计算预算，全文计数继续按字符扣除。Lua 指令、摘要、SQLite 和正文转换使用同一个可信预算，修改 `sai.limits` 无效。成功进入原生转换还消耗一次 `limits.system_calls`；参数或工作预留检查失败不执行转换。

原生计算在阻塞线程执行，等待被取消、局部超时或外层回调失效后不交付迟到结果。输入缓冲与工作预留由实际线程持有，线程退出后才归还额度。解码、第三方转换库内部没有逐步取消入口；宿主在进入、返回、计数块和最终交付时检查取消，因此不承诺立即强制停止正在运行的库函数。

正常完成、库错误和取消均按实际租约释放资源。关闭 Lua 句柄不能提前回收仍被原生线程使用的输入。新回调不能继续使用旧句柄，同一个有效回调可以在可恢复错误后使用原缓冲重新选择较小摘录。

## 实例与验证

[URL 预览包](../../examples/lua-plugins/url-preview/README.md)组合任意来源读取与正文摘录；可拆卸 `web-fetch` 示例使用同一公开接口处理至多 5 MiB 响应，无需私有包身份。

对应契约验证 Unicode 替换与计数、格式、严格参数、输入及 JSON 输出限制、共用预算、关闭及旧句柄。16 MiB 中间结果上限在转换返回后检查，目前没有专门构造超出该上限的回归样本。原生调度的丢弃、超时和取消测试同时覆盖 SQLite 共用路径。HTML 转换库不承诺任意输入恒定耗时，调用者应选择与场景匹配的输入大小和期限。
