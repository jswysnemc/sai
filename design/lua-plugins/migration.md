# 迁移进度

本清单记录长期目标的完成证据。截至第二十二轮，已建立独立运行时、管理入口和二十二个实际迁移包，共提供 39 个插件工具，默认工具总数保持 65。天气、汇率及百科查询使用有界 HTTP，游戏与输入法调查使用通用模型与工具服务编排，系统证据采集使用文件、环境与模板进程接口。AUR 审查与安装使用会话私有存储及工作目录，答复通知使用独立纯回调，图片业务使用二进制、独立视觉和终端能力。哈希解码、玄学抽取与骰子使用零外部权限接口；闹钟使用持久调度、受限路径与主动声音投递。表情库六工具及自动发送已整体迁入 Lua，使用条件索引、删除恢复和独立回复策略接口。其余业务迁移与生态能力继续推进。

## 后续边界

版本 1 已开放有界文本与二进制文件读取、环境读取、模板进程、会话私有存储、插件私有跨会话存储、主动通知、持久命令调度、私有工作目录、二进制传输、目录写入、按文件修订条件发布、单文件删除、系统回收站、终端图片及回复上下文与完成策略。跨插件共享存储、任意改写主 Agent 消息历史、界面组件和远端包分发尚未开放，需要分别设计契约与授权。回收站当前限于 Linux 同文件系统用户回收站，不支持目录回收或跨设备复制。取消不能强制中断已开始的文件 I/O，也不能撤销已经完成的删除或移动；Unix 主动新建会话、脱离进程组的后代也不在原组回收范围。

后续拆分评估对象包括会话清单、知识库、网页正文提取和记忆等仍在宿主中的业务。知识库的共享文件与索引需要先确定通用宿主契约，记忆还要区分工具策略与核心上下文职责。游戏调查、输入法诊断、AUR 审查安装、答复通知策略、图片生成展示、网页搜图、哈希解码、闹钟、玄学抽取及表情库已迁入 Lua。纯粹移动文件不计为插件迁移，会话状态和后台交付事务继续由宿主保证。
