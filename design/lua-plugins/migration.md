## 本地验证记录

2026-09-08，在 Linux 工作区使用锁定依赖完成以下验证：

- `cargo test --locked`：Sai 应用 2,585 项通过、8 项原有测试忽略；独立运行时 17 项通过。应用测试包含 21 项插件集成测试。
- `cargo build -p sai --locked`：新二进制构建成功。生命周期 Future 在构造时装箱，原后台续聊测试及完整回归均通过，没有提高测试线程栈大小。
- Web `npm test`：199 个测试文件、957 项测试通过。
- 从没有主配置的临时 XDG 目录执行插件创建、检查、安装、列举、启用、配置及命令调用；确认管理插件无需模型初始化。随后验证单工具上下文、替换时保留设置、禁用拒绝调用和移除。
- 使用新二进制调用三个迁移工具：DeepSeek 返回组件状态和近期事件；Arch 搜索返回 `printf`、`printf.h` 等真实名称；手册阅读返回正文。
- 伪终端验证 `/plugins`、`/plugin`、`/plugins reload`：未变更插件继续持有原状态，源码更新后创建新实例；调整终端尺寸后用 Ctrl+C 取消等待，本地 HTTP 服务确认连接关闭，下一条插件命令仍成功。

远端测试与构建结果见[该分支的 GitHub Actions](https://github.com/jswysnemc/sai/actions?query=branch%3Afeat%2Flua-plugin-ecosystem)。不同平台的条件编译测试数量可能不同。

## 后续边界

版本 1 尚未开放插件文件与进程能力、持久插件存储、模型上下文变换、界面组件或远端包分发。这些能力需要分别设计宿主契约与授权方式。

后续拆分评估对象包括 Arch Linux 查询、Fcitx Wiki、ProtonDB、搜索供应商、通知与专业诊断。这些功能的注册、配置、权限及数据契约需要分别核对；纯粹移动文件不计为插件迁移。会话状态和后台交付事务继续由宿主保证。
