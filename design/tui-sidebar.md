# 终端侧栏

全屏视图中，侧栏与聊天区固定左右分栏。拖动竖直分界线可调整宽度；普通侧栏和差异审查区分别记住当前会话中的宽度。终端缩窄时限制实际宽度，重新放大后恢复原宽度。

普通侧栏顶部使用独立的品牌区，复用 sai 终端标志，并将 `[x]` 与品牌名称居中对齐。矮屏使用单行品牌名称。关闭按钮悬停时反色，分界线悬停只改变分界线本身，不显示辅助提示。关闭后不会因终端放大自动重新开启。审查区的 `[x]` 退出审查并返回概览侧栏。

命令在空闲和模型生成期间均可执行：

```text
/tui sidebar on     手动开启；非全屏时进入全屏视图
/tui sidebar off    关闭侧栏及当前差异审查
/tui sidebar auto   空间足够时显示，空间不足时隐藏
/tui sidebar        查看当前显示策略
```

配置文件 `config.jsonc` 中的 `display.sidebar` 控制启动默认值：

```json
{
  "display": {
    "fullscreen": true,
    "sidebar": "auto"
  }
}
```

- `auto`：默认值，终端至少 140 列、16 行时显示
- `off`：启动时隐藏，仍可通过命令开启

手动开启需要至少 88 列、8 行，保证聊天和输入区仍有可用空间。命令和关闭按钮只改变当前会话，不写入配置文件。配置刷新不会覆盖手动选择。

右侧面板及分界线延伸到屏幕底部，左侧输入框和正文共用列宽。聊天滚动条与分界线之间保留一列间隔，避免混淆点击区域。各组列表、差异文件列表和差异正文仍独立滚动；拖动分界线不会改变输入光标或创建文字选区。

密集拖动事件按当前鼠标位置合并，不逐条重放已过时的位置。缩窄输入区时，同一帧覆盖右侧旧背景。差异新增行使用绿色背景，删除行使用红色背景，语法着色和文件名固定标题保持不变。

待办在右侧概览默认展开。空间足够时展示完整清单，文件列表保留预览空间；超长清单只在自己的区域滚动。点击待办标题或按 Ctrl+T 可手动收起，缩放不会覆盖手动状态。

差异正文支持直接拖选，松开后通过 OSC 52 复制源代码，不包含行号、增删标记和边框。跨行及横向滚动后的选择使用源文本坐标，拖到上下边缘只滚动差异正文。左侧聊天复制去除两列布局边距，保留正文自身缩进。顶部会话标题不再显示右侧快捷键，复制后仍显示字符数。

顶部聊天标题右侧使用短轨道和百分比指示浏览位置。整个终端最右端的分栏开关可直接开启或关闭侧栏，悬停反色；仅在至少 88 列、8 行时显示。关闭后仍保留开关，不需输入命令即可重新开启。开关不会发送消息或修改磁盘配置。

Unix 使用终端库的普通轮询后端，避免一次读取后剩余事件等待下一次唤醒。就绪检测最多等待 1 毫秒，确保生成期间仍可处理鼠标和键盘。Windows 保留原有输入后端和零等待策略。
