# 普通工具与脚本共用定义和加载状态

默认使用混合工具方式。常驻业务工具保留原生声明，codemode 只描述脚本执行约定，不再重复内联业务说明。模型可直接调用单项工具，也可使用脚本组合调用并过滤中间结果。

Jev 与 load 继续负责延迟工具暴露。完整定义仅进入预选注入或加载结果，供 invoke_tool 和 tools[name](args) 共用，不再同时加入原生声明或脚本说明。脚本目录只包含当前已暴露工具；只读并发和串行执行共同检查加载状态、真实参数、权限和停止状态。DeepSeek 原生别名沿用相同参数适配。

全局 codemode.mode 默认为 on，表示混合；off 表示普通工具；only 表示显式脚本独占。独占方式保留原生 load 和 request_capability，以便取得新工具定义，普通业务调用和 invoke_tool 被拒绝。常驻定义仅在独占方式内联，已加载定义不再次内联。

会话命令与命令行覆盖独立于权限模式，权限切换和计划审批保留完整工具策略。Web 在任务入队时合并默认工具策略并固定组合，后续配置变更不改写已经排队的任务。

Web 请求间隙消息只在所选模式与 Agent 消费时的实时模式相同时合并；不同模式的任务保留在队列中独立执行。计划审批等待期间的工具方式切换以批准交接时的最新选择为准。

描述去重针对当前有效上下文，不承诺整个会话只进行一次网络传输。压缩丢弃定义后重新加载；显式重读允许返回当前完整定义。脚本工作进程内部保存元数据不等于把元数据发送给模型。
