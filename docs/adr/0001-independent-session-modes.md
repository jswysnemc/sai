# 权限模式与工具模式独立

会话分别保存权限策略和工具调用方式。YOLO、人工审核、自动审核、计划模式决定允许的操作与审批方式；codemode 仅决定工具调用是否经由 JavaScript 编排。切换其中一个维度保留另一个维度。

会话对外继续使用可往返解析的模式字符串，例如 `yolo+code-model`，避免改写既有队列、运行请求和计划恢复的数据结构。旧值 `code-model` 解释为人工审核与 codemode 的组合，恢复旧会话时不扩大权限。运行时分别共享权限状态与脚本开关，工具注册表只读取权限状态。

嵌套审批展示实际工具与参数，并关联到外层脚本卡片。审批交互由终端事件循环处理，禁止阻塞脚本截止和取消逻辑。
