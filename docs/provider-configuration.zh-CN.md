# 供应商配置

[English](provider-configuration.md) | [项目说明](../README.zh-CN.md)

## 首次使用

全新安装后，首次进入 `sai` 交互会话或进入 `sai web` 工作台时，会先显示供应商配置引导。选择预设或自定义供应商，填写 API 地址、密钥和默认模型。内置免费供应商 opencode Zen 无需填写个人密钥。

保存后，两端共用配置完成状态，新会话使用刚选定的供应商和模型。引导只校验字段与凭据引用，不会发送模型请求。取消终端引导会退出本次启动，下次仍可继续配置。旧版已有配置保持正常启动，升级无需重新完成引导。

需要认证的供应商支持直接填写密钥，也支持 `$env:VARIABLE_NAME`。环境变量必须存在于 Sai 进程环境中；通过系统服务或容器启动时，也需要向对应进程提供变量。

## Web 设置

进入**设置 → LLM 供应商 → 连接**，或访问 `/settings/providers/connection`。

1. 新增供应商或选择已有供应商，填写 API 地址、协议与凭据。
2. 修改显示名称。新供应商的 ID 默认随名称更新；手动指定独立 ID 后，名称不再影响它。ID 在输入框失焦或按 Enter 时提交，空值和重复值会提示错误。
3. 使用**导入模型**，或在**模型**页签手动添加模型 ID，再到**连接**页签选择默认模型。
4. 点击**保存**。需要切换当前默认供应商时，点击**设为当前**并保存。

修改名称或 ID 后，页面仍选中同一供应商。已保存的密钥和配置中的模型引用会随之保持对应，保存期间继续编辑也不会丢失新修改。密钥默认隐藏，只在主动查看或编辑时显示。如果凭据单独保存在 `secrets.jsonc`，其中的 `api_keys` 条目按供应商 ID 索引，修改 ID 时需要同步调整该条目。

**测试连接**发送一条最小对话请求，**测试工具**检查模型能否发出工具调用。两项测试都不依赖 `/models` 接口，并使用当前草稿，因此可以先测试再保存。

## 终端设置

运行 `sai config`，或在对话中输入 `/config`，进入**供应商和模型**。在供应商列按 `a` 新增，按 Enter 编辑当前供应商。

供应商编辑器分为连接设置、密钥管理和高级请求设置。**测试连接并导入模型**会获取当前草稿对应的模型目录。新增已启用供应商、修改接入地址或凭据、编辑尚未配置模型的供应商时，**保存供应商**也会自动导入模型。已有本地模型继续保留；仅在默认模型为空时，才将首个导入模型设为默认。

**保存供应商**只确认配置界面内的草稿。还需要返回主菜单，选择**保存并退出**并确认，才能写入磁盘。回到同一会话后，`/model` 会读取已保存的配置并列出导入模型，无需重启程序。

仅浏览远端目录不会自动激活全部模型。在模型列按 Tab 切换模型激活状态，按 `a` 手动添加模型 ID。完成后同样需要保存并退出。

## 模型未出现时

| 现象 | 检查方式 |
| --- | --- |
| `/model` 找不到刚配置的模型 | 先完成**保存供应商**，再在主菜单**保存并退出**，并确认供应商已启用。 |
| 供应商不提供 `/models` | 手动添加模型 ID。导入失败不会删除已有本地模型。 |
| 新供应商导入失败，模型列表为空 | 配置可以保存，原激活供应商保持可用。在模型列手动添加模型后再次保存。 |
| 提示环境变量不存在 | 为 Sai 进程设置对应变量并重新启动进程，或在密钥管理中直接填写密钥。 |
| 升级后 Web 仍出现旧问题 | 使用新二进制重启 `sai web` 并刷新页面。手动替换配置前先保留备份。 |

需要切换模型时，输入 `/model`，键入名称过滤，再按 Enter 确认。已停用的供应商不会出现在候选列表中。
