# Sai v0.2.22

本版重塑终端全屏侧栏、配置中心、斜杠命令面板与后台任务管理器的排版和交互，全面补齐鼠标悬停与点击控制，支持明暗终端主题自适应与无 Nerd Font 字体回退，并优化会话切换性能与工具详情收起策略。

## 终端侧栏与全屏阅读

- 侧栏顶栏整体下沉避开右上角分栏按钮，将工作区目录与 Git 分支分两行独立展示；移除横向实线与虚线，改用透明呼吸留白、强调色折叠箭头与加粗标题区分模块，并按横向对称边距与纵向黄金比例使 `Sessions` 等分组贴合侧栏视觉中线。
- 上下文进度条切换为同基线单轴横线方案（`━` / `─`），在 `72%` 与 `90%` 水位切换预警色，侧栏、`/context` 浮层与自动压缩配置预览保持一致；支持 `F6` 配合 `f` 或数字键 `1`–`5` 单区手风琴聚焦。
- 会话分组保留当前会话左侧异色竖条标识，按运行中、就绪、今天、近 7 天与更早归类；全屏切换会话跳过内联滚回输出并复用缓存文档，消除切换闪烁与原始转义串暴露。
- 悬停或手动展开工具与思考详情期间自动锁定视口与折叠状态，避免流式输出抢占焦点；移开指针后恢复正常跟随，`Show earlier steps` 保留内部子步骤展开状态。
- 点击“回到底部 / 有新输出”胶囊或按 `Ctrl+End` / `Ctrl+Down` 回到底部时，自动收起可视区域外的工具详情，仅保留底部当前可见区域内的已展开项。

## 配置中心、命令面板与交互

- 重构 `sai config` 配置仪表盘与首次运行引导向导，精简供应商与端点多步表单，窄终端（`< 92` 列）自动切换上下堆叠布局；全界面支持鼠标点击、滚轮浏览、悬停高亮与宽字符安全编辑。
- 重构 `/` 斜杠命令面板，按功能分类组织命令并提供可滚动视口；斜杠面板与 `@` / `#` 引用补全面板均支持鼠标悬停、点击补全与滚轮翻页。
- 重构 `/ps` 后台任务管理器，宽屏采用主从分栏、窄屏自动堆叠；命令行文本支持环境变量、内置命令、参数、字符串与管道重定向着色，支持按 `c` 或点击展开查看完整多行命令。
- `/model` 与子任务模型选择器补齐页签、列表项与底部动作按钮的鼠标悬停反馈，支持点击进入自定义上下文上限输入并修正宽字符光标列对齐。
- 提问面板支持鼠标点选选项、滚轮滚动与题间导航；权限审批提示增加流式防误触保护、鼠标点击选择与拒绝回复粘贴净化；嵌套备用屏引用计数消除全屏下打开 `/config`、`/resume`、`/ps`、`/help` 时的闪屏。

## 主题调色板与字体兼容

- 悬停高亮按比例提亮或压暗前景色，完整保留代码语法色相与差异背景；结合终端探测与 `COLORFGBG` 环境变量适配深色和浅色终端，统一覆盖配置面板、选择器、补全框、差异块与提问卡片。
- 新增 `SAI_NERD_FONT=0` 环境变量开关，禁用私有区图标字形时自动回退至标准单列宽几何字符；全屏欢迎区将权限模式徽标紧凑对齐于版本号右侧。

## 构建与下载

统一 CLI、Web、桌面端与发布标签版本至 `0.2.22`，全部 Rust 目标与测试通过 `-D warnings` 零警告校验及伪终端交互回归测试。

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制，Linux x86_64/ARM64、macOS x86_64/ARM64、Windows x86_64 桌面安装包，以及 Web 静态资源包。下载产物附带 SHA-256 校验文件。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.22
```
