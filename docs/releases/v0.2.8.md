# Sai v0.2.8

本版改进桌面端标题栏交互体验，修复 Windows 控制台尺寸与换行渲染错位问题，优化折叠工作日志和文件变更列表展示。

## 新增

- 网页端连续读取折叠：连续执行的已完成读取工具自动聚合为紧凑折叠组，执行中的项目保持独立展开。
- 网页端改动文件路径展示：工作区内的变更文件优先展示相对目录，避免过长绝对路径挤压行内统计。

## 改进

- 工作日志状态摘要：在折叠态工作日志中细分工具调用类别（读取、写入、命令等），提供更清晰的执行摘要。
- 树状目录视觉层级：修复文件树引导线穿透问题，优化选中与悬停状态下的对比度。

## 修复

- Windows 控制台尺寸同步：解决终端尺寸变化时将缓冲区高度误识别为可视高度导致的内容跳动问题。
- Windows 桌面控制按钮命中：确保标题栏控制按钮在非透明背景下正常响应点击与窗口操作。
- 差异卡片背景透明度：修正差异文件卡片标题区域背景，避免滚动时内容重叠透视。

## 升级

使用新二进制重新启动 `sai web`，然后刷新页面。配置与会话继续沿用，无需重置。

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制及配套 SHA-256 文件，以及各平台桌面安装包。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.8
```
