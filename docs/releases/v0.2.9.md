# Sai v0.2.9

本版新增原生桌面自动化 Computer Use、用量活跃度 52 周热力图与会话阅读偏好设置，重构设置页双栏与表单视觉交互，并改进 TUI 提问弹层与终端作业控制。

## 新增

- 桌面自动化 Computer Use：接入原生桌面自动化工具，在设置页提供官方驱动（cua-driver）一键安装、版本检测与驱动状态展示。
- 网页端用量活跃度分析：全新用量概览支持 52 周热力图、连续打卡天数统计以及实时/缓存 Token 维度对比。
- 网页端会话阅读偏好：支持在设置中自定义会话字体、字号及栏宽，偏好在本地浏览器持久化保存。
- 记忆双栏管理工作区：将记忆管理重构成左侧分类导航、右侧常驻详情的双栏界面，支持快速切换、编辑与关联跳转。

## 改进

- 设置中心视觉重构：设置页采用白瓷级页面边框，左侧导航与右侧卡片式表单布局统一，保存操作栏常驻停靠于底部，Agent 工具权限支持右侧抽屉式参数结构展示。
- 全屏 TUI 用户提问弹层：提问交互以浮动卡片覆盖于输入区之上，无需切出全屏或进入独立备用屏，各选项描述常驻展开。
- TUI 消息队列容错保留：运行失败或被打断时自动保留未消费的提交队列，并在输入框已有草稿时暂存斜杠命令。
- 文本选区与复制优化：全屏视图滚动与选区保留文档树结构，并在多行复制时加速 ANSI 样式剥离。

## 修复

- 控制终端作业控制与信号隔离：Unix 环境下子进程自动脱离控制终端会话，避免执行交互式程序后终端捕获 SIGTTIN 导致进程挂起。
- 工具产物归档文件名超长截断：针对包含思维签名的大模型工具调用 ID 进行截断与哈希保护，避免超出系统 `NAME_MAX` 限制。
- 运行日志与流式事件重放修复：修复会话日志重放过期历史与结束事件排队时可能遗漏终态事件的问题。

## 升级

使用新二进制重新启动 `sai web`，然后刷新页面。配置与会话继续沿用，无需重置。

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制及配套 SHA-256 文件，以及各平台桌面安装包。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.9
```
