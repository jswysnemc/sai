# Sai v0.2.5

本版新增桌面安装包、Brave 与 Exa 网页搜索、文件树多选，并重做终端轮次统计与工具状态行。

## 新增

- 桌面安装包：基于内嵌 Web 的同一后端，提供 Linux AppImage / tar.gz、macOS dmg / zip、Windows exe / zip。`sai web` 支持后台常驻。
- 网页搜索新增 Brave（订阅令牌）与 Exa（语义检索），环境变量分别为 `BRAVE_API_KEY`、`EXA_API_KEY`，自动回退顺序位于 AnySearch 之后。
- 文件树多选：Ctrl/⌘ 点击自由增减，Shift 点击或 Shift+方向键选区间，Ctrl/⌘+A 全选，Delete 批量删除；多选时显示计数条，右键可批量复制路径与删除。
- 右键菜单：会话侧栏空白处（新建会话、搜索、批量选择、展开历史、刷新）；文件首页的最近文件与空白处（打开、定位、复制路径、移出最近、新建文件、清空最近）。
- 模型选择按供应商二级分组，搜索时仍按供应商归组。

## 改进

- 终端轮次统计改为靠左单行并与分割线合一：`Worked for · 完成时刻 · First word · ↑ 输入 · ↓ 输出 · 缓存命中 · 速度`。默认使用 Nerd Font 图标，`SAI_NERD_FONT=0` 回退为字符与文字。退出后重新进入会话，每轮统计照常恢复。
- 内置、浏览器、记忆、目标、SSH 与 MCP 工具的状态行使用专用动词并显示操作对象，不再只有 `Running` 与工具名。
- 输入框只显示模型名末段（如 `deepseek-v4-flash`），推理强度去掉图标并与模型名对齐；思考区恢复原图标。
- 多密钥改为紧凑行；密钥直接以圆点掩码显示，无需先点编辑，清除按钮改为删除。网页搜索的密钥行可整行删除。
- Jev 预选时，已在上下文中的片段只给提示，不再重复注入正文。

## 移除

- 删除不再使用的 Rust 依赖 `rustyline`、`syntect`、`termimad`。

## 升级

使用新二进制重新启动 `sai web`，然后刷新页面。配置与会话继续沿用，无需重置。

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制及配套 SHA-256 文件，以及各平台桌面安装包。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.5
```
