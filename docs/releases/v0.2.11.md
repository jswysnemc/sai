# Sai v0.2.11

本版新增可配置的 DeepSeek 终端样式与分动作桌面工具，扩展代码语法着色和图表渲染，并修复未分类标识符配色、桌面启动路径判断及 DeepSeek Responses 推理参数格式。

## 新增

- DeepSeek 终端样式：保留经典样式，使用 `sai --style deepseek` 或 `/style` 切换。工具与思考先展开，较旧详情被新步骤完全推出十行窗口后才自动折叠；支持手动展开、历史步骤收起与链内滚动。
- 紧凑工具展示：统一语义化标题、状态颜色与缩进，减少重复信息；Markdown 无序列表使用小圆点，续行保持对齐。图片读取与用户图片附件沿用 Kitty 协议或终端回退预览，展开时靠左展示。
- 原生桌面工具族：保留 `computer_use`，新增 12 个分动作入口，共享驱动连接和快照；支持截图裁剪、缩放、帧坐标投影、控件文本与值查询、默认动作及菜单操作。
- 代码与图表渲染：使用 Syntect 扩展语法支持，并通过 Pele 渲染图表。

## 修复

- 未分类标识符配色：恢复原有主色，保持字符串、注释等已分类内容的颜色；纯文本不插入着色序列。保留原失败断言并补充回归测试。
- 桌面启动路径：解析启动路径后再比较工作区参数，避免不同路径表示导致错误判断。
- DeepSeek Responses 参数：按嵌套结构发送推理强度参数。
- 终端交互与回放：优化折叠层级、状态过渡、输入框上方的等待提示、图片布局和后续用户消息展示。

## 升级

经典终端样式仍为默认选项，原有配置与会话继续沿用。桌面操作默认关闭，需要用户显式启用 `computer_use.enabled` 并授予驱动系统权限；输入保持后台、窗口定向与快照消费约束，子代理不会继承桌面工具。详见[原生桌面操作说明](../computer-use.md)。

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制与 SHA-256 文件，以及 Linux x86_64/ARM64、macOS x86_64/ARM64、Windows x86_64 桌面安装包。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.11
```
