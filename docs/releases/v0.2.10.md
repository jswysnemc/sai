# Sai v0.2.10

本版新增内置浏览器 HTML 文件预览、界面与代码编辑器字体偏好设置、剪贴板多图粘贴附件支持，并修复 Windows 平台子进程闪烁控制台窗口、终端 WebSocket 输出滞后丢字与 CLI 流式渲染换行计算等问题。

## 新增

- 内置浏览器 HTML 预览：在工作区文件树、文件主页以及编辑器右键菜单中支持直接在内置浏览器面板打开并预览 HTML 文件，提供安全沙箱预览路由。
- 字体偏好设置与字族选择器：在外观设置中支持自定义界面字体和等宽编辑器字体，桌面端支持自动读取系统已安装字体族列表并提供预览选择。
- 剪贴板多图粘贴与附件支持：网页端对话输入框与 CLI 终端均支持连续粘贴或附加多张剪贴板图片，并在排队提交与历史回放中完整保留全部图片数据。

## 修复

- Windows 子进程控制台窗口弹窗抑制：在 Windows 桌面端为 Git、搜索和命令行等子进程设置无窗口标志，避免执行背景任务时频繁弹出控制台黑框。
- 终端 WebSocket 输出滞后游标补齐：在终端广播通道发生滞后时，按累计字节游标自回放缓冲中补齐遗漏分片，避免终端显示丢字。
- CLI 流式渲染换行与擦行计算修复：修正终端软换行与终端整宽行数计算，防止流式输出在清行时误擦上一行已提交的内容。
- 大语言模型供应商错误载荷简化：简化供应商错误响应的数据结构，并稳定终端输入队列的测试用例。

## 升级

使用新二进制重新启动 `sai web`，然后刷新页面。配置与会话继续沿用，无需重置。

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制及配套 SHA-256 文件，以及各平台桌面安装包。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.10
```
