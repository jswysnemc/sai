# Sai v0.2.6

本版让终端折叠预览可按需配置，并集中修复终端轮次统计、命令输出与网页设置的显示问题。

## 新增

- 终端折叠预览可配置：输出、命令、思考与工具载荷的折叠保留策略支持「保留开头」「保留首尾」「全部省略」三种模式，开头与结尾保留行数可分别调整（默认开头 2 行、结尾 4 行，各自上限 24）。终端 `sai` 的显示偏好与网页「终端与输入」面板均可设置，网页端以纸带示意图预览保留与省略的行。

## 改进

- 终端页脚只显示模型名末段，并在工作目录后追加当前 Git 分支，去掉按键行的 PgUp/PgDn 提示。
- 终端轮次统计恢复行首圆点、24 小时时钟与首字延迟标签；网页搜索与文件搜索使用各自动词与结果徽标。
- 全屏表格限制在正文宽度内，不再与右侧概览栏重叠。
- 终端解析 CommonMark 行内代码（含嵌套标记），表格单元格不再残留反引号。
- 网页 Jev 卡片改为一句概述，展开的清单里工具与 Skill 可分别查看参数与 Skill 文档。

## 修复

- 终端悬停改为提亮前景并取消暗淡属性，不再依赖加粗，指针停在「回到底部」按钮上时同样生效。
- 网页上下文用量跟随当前查看的会话，不再停留在空白的新会话上。
- 网页消息导航的行号栏按位数对齐，思考视图按整行滚动，最新一行不再被截断。
- 网页新建会话所选模型若来自已停用的供应商，会保留该选项并给出内联错误阻止保存；停用该供应商时先确认，再清除默认模型并提示。

## 升级

使用新二进制重新启动 `sai web`，然后刷新页面。配置与会话继续沿用，无需重置。已有的显示配置缺少折叠字段时回退默认（保留首尾，开头 2 行、结尾 4 行）。

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制及配套 SHA-256 文件，以及各平台桌面安装包。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.6
```
