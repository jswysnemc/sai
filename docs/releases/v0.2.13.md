# Sai v0.2.13

本版新增终端底栏文本拖选复制、子任务运行统计与树形结果排版，优化提问卡片、后台命令、待办事项及文件搜索等工具的预览与上下文展示；独立度量推理用时，并修复转义序列解析、光标重复重绘与若干终端交互问题。

## 新增

- 底栏拖选复制：终端底部的状态栏与快捷键提示行支持鼠标拖选高亮与剪贴板复制，选区与输入草稿相互隔离，不影响输入内容与光标位置。
- 子任务统计与树形排版：子任务卡片与执行链时间线摘要展示真实步数调用、token 用量及执行耗时，完成结论采用树形前缀（`└ `）清晰展示。
- 工具卡片预览精细化：后台任务显示精简短标识与交互引导；文件搜索标注过滤条件与匹配统计；待办事项补充视觉进度条与状态汇总；计算机使用与交互类工具增加上下文语义化说明与安全文本脱敏。
- 上下文压缩编辑器：更新上下文压缩交互界面与编辑器支持。
- 工具卡片演示套件：新增全量工具卡片渲染演示用例与新旧视觉对比测试套件，提供终端运行演示脚本。

## 修复与优化

- 提问结果展示：提问卡片在完成状态下仅保留已选选项标签与自定义答案，未选项目不再残留；等待回答阶段维持完整选项展示。
- 推理时间隔离：独立度量并展示思考推理耗时，隐藏常规文件读取的耗时干扰，避免时间度量混淆。
- 终端协议与转义处理：过滤残缺控制序列，修复畸形序列后的 UTF-8 编码保留，消除冗余的光标重绘。
- 界面流畅度提升：流式响应片段采用增量渲染，降低终端刷新负载；修正状态动画交接与启动时序。

## 升级

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制与 SHA-256 文件，以及 Linux x86_64/ARM64、macOS x86_64/ARM64、Windows x86_64 桌面安装包。

