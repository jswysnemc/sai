# Sai v0.2.16

本版修复 codemode 嵌套权限审核导致终端等待的问题，将权限策略与脚本编排独立设置，并为 JavaScript 工具卡片增加语法着色。

## 修复与改进

- 嵌套工具的权限请求显示在所属 codemode 卡片中，展示实际工具和参数；缺少所属卡片时仍会显示审核入口。
- 审核输入使用终端事件循环处理，等待期间可正常取消、超时和切换权限策略。
- YOLO、人工审核、自动审核和计划模式均可与 codemode 组合。`/code-model` 只切换脚本编排，Shift+Tab 只切换权限策略。
- 支持 `sai --yolo --code-model`；单独使用 `--code-model` 保留配置中的权限策略。旧会话的 `code-model` 设置继续使用人工审核。
- JavaScript 语法着色覆盖运行中、已完成和详情视图，保留缩进与多行语法状态。
- Web 静态资源独立打包并校验摘要，首次启动按 CLI 版本下载；`sai web update` 可更新缓存。
- 发布工作流检查 CLI、Web、桌面和标签版本一致，并执行 codemode 权限、超时、模式切换与语法着色回归。

## 下载与升级

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制，Linux x86_64/ARM64、macOS x86_64/ARM64、Windows x86_64 桌面安装包，以及 Web 静态资源包。各下载产物附带 SHA-256 校验文件。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.16
```
