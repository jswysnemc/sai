# Sai v0.2.3

本版加入内置浏览器和首次供应商配置引导，修复 Web 供应商改名无法保存、TUI 保存接入后 `/model` 缺少新模型的问题，并改进终端会话交互。

## 供应商配置

- 首次使用 TUI 或 Web 时引导选择供应商、填写凭据和默认模型；任一端保存后，两端共用完成状态。旧版已有配置无需重新引导。
- Web 修改供应商名称或 ID 后保持当前选中项，保留已保存的密钥，并同步配置中的模型引用。支持保存期间继续改名，拒绝空 ID 和重复 ID。
- TUI 新增供应商或修改接入后，保存时自动导入模型。完成主菜单的“保存并退出”后，同一会话中的 `/model` 即可选择新模型。
- 导入失败时保留本地模型；尚无模型的新供应商不会替换原激活项，仍可手动添加模型。

参见[供应商配置指南](https://github.com/jswysnemc/sai/blob/v0.2.3/docs/provider-configuration.zh-CN.md)。

## 内置浏览器

- Web 工作台提供浏览器面板，支持标签页、导航、鼠标键盘操作、输入法与粘贴。
- 单一 `browser` 工具通过 `action` 执行导航、页面快照、截图、元素交互与脚本求值；权限按具体动作判断。
- 支持高像素密度画面、自由视口尺寸、网页元素选取并加入聊天上下文、文件上传和下载、页面对话框与选择菜单。
- 浏览器使用 Sai 独立用户目录保存登录状态，可清除浏览数据，也可通过 `SAI_BROWSER_PROFILE=temp` 使用临时目录。调试入口仅限本机访问。

内置浏览器需要在运行 Sai 的机器上安装 Chrome、Chromium 或 Edge；可通过 `SAI_BROWSER_EXECUTABLE` 指定路径。发布二进制与默认 Docker 镜像不捆绑浏览器。

## 终端交互

- 全屏会话中，命令与输出分别折叠；鼠标悬停时突出显示可展开区域。
- “回到底部”按钮位于输入区上方，避免重复展示新输出提示。
- 退出时检查子代理和后台命令，提供停止任务后退出、保留后台命令退出或取消退出的选择。
- 更新中英文文档及界面截图说明。

## 升级

替换二进制后重新启动 TUI 或 `sai web`；Web 页面需要刷新以加载新资源。现有配置、会话和凭据文件继续使用，无需重置。单独存放在 `secrets.jsonc` 的密钥按供应商 ID 索引，手动改 ID 时需同步调整对应条目。

下载包含以下二进制及配套 SHA-256 文件：

- `sai-linux-x86_64`
- `sai-macos-arm64`
- `sai-windows-x86_64.exe`

Docker 镜像：

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.3
```
