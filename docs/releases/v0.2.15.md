# Sai v0.2.15

本版新增 TUI 思考与长文本输出双色引导线滚动交互，引入支持多文件事务化变更的 `apply_patch` 工具，将后台任务面板原生嵌入全屏侧边栏并模块化 REPL 后台管理器；同时针对 Chafa 终端图片回退与前端语法高亮依赖完成修复。

## 新增

- TUI 思考滚动引导线：终端全屏模式下为思考过程与大段输出增加双色引导线，轨道与高亮滑块直观呈现当前阅读位置与全文比例，支持平滑滚动与段落交互。
- 多文件补丁工具 `apply_patch`：支持跨文件的添加、就地修改、重命名及删除，写入前统一校验，运行时提交失败后尝试回滚并明确报告恢复不完整。多文件提交不保证进程崩溃时的原子性。
- 侧边栏原生集成后台任务：在全屏 REPL 侧边栏内嵌后台任务面板，支持快捷查看和管理后台运行命令；重构后台任务生命周期与事件通知流。
- Web 任务仪表盘精细化：优化 Web 端后台任务列表的状态刷新、日志流展示与管理交互。

## 修复与优化

- 终端图片 Chafa 格式回退：修正 Chafa 图片渲染在特定字符终端下的输出格式，强制使用 symbols 模式避免乱码。
- 前端代码高亮依赖：补充 lezer-common 依赖包引用，确保复杂语法树解析运行稳定。
- 跨平台补丁测试：规范化临时目录路径，兼容 macOS 的系统目录软链接与 Windows 短路径别名；回滚断言按实际目标路径校验，保留补丁目标的链接保护。
- 补丁路径校验：在路径拼接前拒绝原始输入中的父目录跳转，避免 Windows 逐字路径提前规范化后漏过检查。
- 全屏终端文本交互：优化窄终端下标题折行与正文紧接呈现，修复带引导线文本的换行复制行为。

## 升级

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制与 SHA-256 文件，以及 Linux x86_64/ARM64、macOS x86_64/ARM64、Windows x86_64 桌面安装包。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.15
```
