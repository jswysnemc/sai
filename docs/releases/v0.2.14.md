# Sai v0.2.14

本版新增全屏图片查看器与会话选择器异步工作区加载，优化侧栏与待办队列交互流、品牌对齐及子智能体视图模式继承；改进微信消息来源识别与代码模式超时控制，并修复慢速取消锁等待、侧栏悬停快照竞争与并发测试稳定性。

## 新增

- 全屏图片查看器：新增全屏图片交互查看支持，提升图片浏览体验与操作便捷度。
- 侧边栏与队列面板交互重构：精细化侧边栏与任务排队面板交互流程，统一品牌标识与欢迎页排版，优化评审悬停引用交互。
- 异步工作区加载：命令行会话选择器采用异步方式加载完整工作区信息，杜绝大型工程下工作区扫描对界面的阻塞。
- 子智能体展示模式继承：子智能体运行视图自动继承主界面的演示模式与个性化显示选项，保持全流程界面视觉一致。

## 修复与优化

- 微信消息来源识别与代码模式：增强对微信渠道消息来源的准确判定，稳定代码模式执行超时控制。
- 锁竞争与取消机制：为慢速遗留取消锁引入有界等待策略，避免高并发压力下线程过早失败。
- 测试与回归稳定性：侧边栏拖拽悬停测试采样前等待 Git 状态平稳；规范会话创建测试中的工作区绝对路径解析；容忍 CI 调度延迟对嵌入并发校验的偶发影响。

## 升级

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制与 SHA-256 文件，以及 Linux x86_64/ARM64、macOS x86_64/ARM64、Windows x86_64 桌面安装包。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.14
```
