# Sai v0.2.4

本版修复 Web 聊天输入框删除文字后增高，以及消息导航条与 Markdown 正文重叠的问题。

## 修复

- 合并浏览器自动补出的末尾换行与输入框占位节点。删除多行文字时高度正常收缩，删空后恢复原始高度；保留真实空行及撤销、重做行为。
- 消息导航条可见时，为消息正文和输入区统一预留间距。宽屏保持内容居中，移动端和窄面板隐藏导航条时不增加额外留白。
- 修正 Linux 终端回归测试的进程启动时序：等待后台命令实际启动后再验证退出，并排除其他会话中的进程。

## 升级

使用新二进制重新启动 `sai web`，然后刷新页面。配置与会话继续沿用，无需重置。

提供 Linux x86_64、macOS ARM64、Windows x86_64 二进制及配套 SHA-256 文件。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.4
```

本版包含 [v0.2.3](https://github.com/jswysnemc/sai/releases/tag/v0.2.3) 的供应商配置与内置浏览器功能。完整变更：[v0.2.3...v0.2.4](https://github.com/jswysnemc/sai/compare/v0.2.3...v0.2.4)。
