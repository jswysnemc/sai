# Sai v0.2.20

本版改进终端阅读、输入框和会话侧栏，支持运行期间调整模型设置，并完善跨平台沙箱、工具执行和会话恢复。

## 终端交互

- 工具标题在正文滚动时固定于视口顶部，进入下一张卡片时更新标题；悬停只高亮标题，保留代码语法颜色与差异背景。
- 工具输出和思考窗口常驻左侧引导线，滑块保持固定长度，悬停或拖动时加宽。主会话滚动条支持跨越侧栏拖动和释放。
- 新增 `/tui input panel` 和 `/tui input separator`，支持面板与简约分割线输入框，样式选择持久化到配置并参与命令补全。
- 侧栏使用紧凑的工作区、分支和用量布局，按 Subagents、Todo、Changes、Sessions、Background tasks 排列分组。
- 当前会话固定显示在会话列表首位，其余会话按运行、就绪和近期状态分组；支持在会话之间切换并恢复阅读位置。
- `/model`、`/providers`、`/think`、`/thinking` 在运行期间立即响应，更新后的设置从下一次模型请求开始生效。
- 底栏、队列和侧栏入口使用主题前景色表示悬停，文字选择保留独立的反色样式。

## 执行与恢复

- 持续目标支持运行期间暂停、恢复和调整边界；主会话、子会话与上下文压缩共享预算计量，并避免重复计费。
- 工具进度支持并发流式显示，逐项保存完成结果；已确认的只读调用可在模型流结束前执行，并随轮次取消失效。
- 支持带伪终端输入的交互命令会话，在任务侧栏中管理会话与后台命令。
- 子会话保存执行检查点并压缩长上下文；上下文摘要支持预计算、来源校验和取消。
- Windows 命令通过 AppContainer 与进程作业隔离，完善路径授权、PowerShell 工作目录与进程清理；受限网络通过获准域名代理访问。
- 邮件钩子诊断与终端输出分离，避免破坏界面绘制；Web 静态资源指针更新支持并发写入。

## 构建与下载

清理 Rust 编译警告，统一 CLI、Web、桌面和发布标签版本。修正 macOS 的平台导入，主程序调试构建启用轻量优化以控制展开表体积，并保留默认 panic 展开机制。更新已弃用的原子操作，为插件超时恢复测试保留并行调度预算。Windows 代理函数、进程字段和钩子分支按实际平台使用范围编译。CI 与发布构建将 Rust 编译警告视为错误。

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制，Linux x86_64/ARM64、macOS x86_64/ARM64、Windows x86_64 桌面安装包，以及 Web 静态资源包。下载产物附带 SHA-256 校验文件。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.20
```
