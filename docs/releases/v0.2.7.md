# Sai v0.2.7

本版带来一体化桌面顶栏设计，改进全屏终端交互体验，并修复输入框与富文本渲染问题。

## 新增

- 桌面一体化顶栏：移除了桌面客户端顶部的独立标题栏，将 Sai 工作台自身的顶行（侧边栏顶部、会话顶栏、工作区页签与设置顶栏）直接作为窗口标题区域；Windows 与 Linux 在右上角叠加透明窗口控制按钮（最小化、最大化、关闭），macOS 保留原生红绿灯按钮并自适应顶行内边距，双击顶行空白处可切换最大化。

## 改进

- 全屏 TUI 控制行交互收敛：只有折叠提示行（`lines hidden`）以及展开态末尾追加的收起行（`Show less`）响应鼠标点击展开/收起和悬停提亮，正文文本行不再误触发折叠，避免选词拖拽或查看时的误触。
- 全屏 TUI 语法颜色保留色相：语法高亮等有色相的前景在悬停提亮时进行通道差值保护，避免整块代码颜色被漂白。
- 回到底部按钮悬停优先级：当正文最后一行同时存在折叠提示与「回到底部」浮动按钮时，鼠标悬停优先判定为按钮。

## 修复

- 网页端折叠光标滚动定位：修复换行后光标矩形为零时触发输入区异常跳到底部的问题，采用临时测距探针精准获取折叠光标的实际几何位置。
- 网页端工作流部件分组：过滤轮次之间仅含换行的空白正文片段，避免 Gemini 等模型在思考与工具之间输出换行导致活动卡片分组被打断。
- 网页端有序列表渲染：将有序列表首个段落设为行内显示，防止数字编号与段落文本分行。

## 升级

使用新二进制重新启动 `sai web`，然后刷新页面。配置与会话继续沿用，无需重置。

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制及配套 SHA-256 文件，以及各平台桌面安装包。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.7
```
