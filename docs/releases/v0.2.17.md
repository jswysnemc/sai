# Sai v0.2.17

本版包含 codemode 权限卡片、独立会话模式和 JavaScript 着色改进，并将完整终端回归加入发布检查。

## 功能与修复

- 嵌套工具权限请求显示实际操作和参数，等待审核期间可以正常取消和超时。
- 权限策略与 JavaScript 工具编排独立设置，支持 `sai --yolo --code-model`。`/code-model` 只切换编排方式，Shift+Tab 只切换权限策略。
- codemode 运行中、完成后及详情视图均支持 JavaScript 语法着色。
- Web 静态资源按 CLI 版本独立下载，支持摘要校验和 `sai web update`。
- 修正流式参数测试中的 JSON 换行转义，保留原有滚动和位置断言。
- 模型选择测试使用不受终端宽度影响的标题判断就绪；悬停测试验证当前背景高亮行为。
- 发布前必须通过完整终端回归、codemode 集成回归、Web 测试及版本一致性检查，再发布各平台安装包。

## 下载与升级

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制，Linux x86_64/ARM64、macOS x86_64/ARM64、Windows x86_64 桌面安装包，以及 Web 静态资源包。各下载产物附带 SHA-256 校验文件。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.17
```
