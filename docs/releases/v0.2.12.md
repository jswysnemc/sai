# Sai v0.2.12

本版将线性执行链全屏界面设为默认终端视图，删除旧的全屏分段渲染，并精简各类工具结果展示；`/context` 改为居中浮层，同时修复悬停箭头、子任务结论缺失与若干展示问题。

## 新增

- 默认全屏视图：启动即进入线性执行链全屏界面，`Ctrl+O` 在全屏与内联视图间临时切换。新增 `sai --view fullscreen|inline` 与 `/view` 命令，`/view` 保存默认偏好。
- 上下文浮层：`/context` 以居中浮层展示分段柱图、各分类占用与比例、空闲区和自动压缩预留，底部显示本轮输入、缓存命中、缓存写入与输出；按 `Esc` 关闭，窄终端改为上下排列。
- 工具结果精简：目标、文件查找、文件搜索、系统信息、回收站、后台清理、MCP 管理、能力加载、子代理、网页搜索与浏览器截图使用专用摘要，收起和展开状态均不显示内部 ID、时间戳、参数定义、技能正文与空协议字段。
- 图标与标记：命令使用终端窗口图标，文本搜索与网络搜索区分图标，工具与思考分组使用语义图标，底部工作状态改为环形活动图标；写入与替换标题的增删行数使用绿色与红色。

## 修复

- 悬停展开／收起：仅在悬停标题首行时按实际状态显示 `▸` 或 `▾`，移到正文后恢复；`Hide earlier steps` 不再出现两个箭头；底部待办和子代理面板按实际展开状态显示箭头。
- 标题信息：子代理与提问条目在首行显示任务或问题，删除待办条目时显示条目内容。
- 子代理结论：执行链展开正文显示子代理的最终结论，不再只显示运行状态。
- 命令折叠：命令与输出共用一个标题控件，单个步骤也可从首行收起。
- 阅读位置：执行链滚动轨道改为阅读位置百分比。
- Markdown 列表：无序列表统一圆点、层级缩进与续行对齐。

## 升级

旧配置中的 `display.tui_style` 仍可读取，但不再写入：`deepseek` 迁移为全屏视图，其余情况由 `display.fullscreen` 决定，默认值为全屏。需要内联视图时，可将 `display.fullscreen` 设为 `false`，或使用 `sai --view inline`、`/view inline`。`--style` 作为 `--view` 的兼容别名保留，其中 `classic` 对应内联视图，`deepseek` 对应全屏视图；`/style` 命令已由 `/view` 取代。

提供 Linux x86_64、macOS ARM64、Windows x86_64 命令行二进制与 SHA-256 文件，以及 Linux x86_64/ARM64、macOS x86_64/ARM64、Windows x86_64 桌面安装包。

```bash
docker pull ghcr.io/jswysnemc/sai:0.2.12
```
