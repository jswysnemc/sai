# TUI 提问交互

提问卡片使用圆角细边框和终端默认背景，宽度最多 88 列；窄窗口自动省略边框。提问前清除输入区旧底色，回答摘要沿用同一套卡片样式。

提问面板按问题进度、正文、选项和操作提示排列。顶部显示单选／多选及必答／可跳过状态。单选使用空心／实心圆，多选使用空心／实心方块；箭头独立表示当前焦点。问题导航使用菱形标记当前题、实心圆标记已回答题，窄屏优先保留当前题。当前选项使用青色强调，只展开当前选项说明；默认答案对应初始焦点。

| 操作 | 按键 |
| --- | --- |
| 移动选项焦点 | 上下方向键，或 j / k |
| 单选确认、打开自定义答案编辑 | Enter |
| 按编号选择选项（多选时切换勾选） | 1–9 |
| 多选勾选或取消勾选 | 空格 |
| 多选继续到下一题或确认页 | Enter；焦点在自定义答案时进入编辑 |
| 切换问题 | Tab / Shift+Tab，或左右方向键 |
| 保存自定义答案 | Enter |
| 自定义答案换行 | Ctrl+J |
| 放弃本次编辑，保留原答案 | Esc |
| 取消整次提问 | 两秒内按两次 Esc，或 Ctrl+C |
| 确认页滚动查看答案 | 上下方向键 |
| 确认页提交 | Enter |

单个单选问题在确认答案后直接提交；多选或多题请求进入确认页。必答问题未回答时，提交会返回第一个未回答问题。切换问题不会清除已经选择的答案。

长问题和选项按终端显示宽度换行；小窗口优先保留当前选项或编辑行。面板采用差异绘制，空闲轮询不再反复清空整块区域。

相关实现位于 `src/question_tui/`，分别负责事件循环、交互状态、终端生命周期、页面布局和绘制。

`ask_question` 的单选和多选始终提供“其他”（Other）选项，旧请求中的 `custom: false` 会在工具入口规范化为 `true`。通用表单的约束保持原有语义。选择“其他”后输入答案，Enter 保存，Esc 放弃本次编辑。多选可同时提交预设选项和自定义答案；填写后按编号或空格切换勾选，Enter 重新编辑。

工具等待回答时显示 `Asking`（中文“等待回答”），结束后显示 `Asked`（中文“已提问”）；取消或失败仍保留对应状态提示。
