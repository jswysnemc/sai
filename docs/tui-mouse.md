# TUI 鼠标操作

内联和全屏视图的默认底栏均支持单击与前景悬停高亮：

| 字段 | 操作 |
| --- | --- |
| 模型 | 打开 `/model` 选择器 |
| 思考等级 | 打开 `/thinking` 选择列表 |
| 上下文占用 | 打开 `/context` 查看面板 |
| 权限模式 | 与 `Shift+Tab` 相同，切换权限策略并保留工具模式 |

单击在同一位置松开鼠标后生效。拖动仍用于选择文字，通过 OSC 52 复制；拖回起点不会触发单击。打开和关闭底栏面板会保留输入草稿、附件及光标位置。裁掉的字段、字段间空白和插件自定义状态栏不会产生默认字段动作。

`/` 斜杠命令面板与 `@`、`#` 引用补全面板支持鼠标悬停高亮、单击直接补全及滚轮翻页。

`/model` 与子任务模型设置支持对顶部页签、供应商与模型行、思考等级、上下文上限（含点击激活自定义输入）以及保存、取消、子任务设置按钮的悬停高亮与单击切换；滚轮移动所在列的选项，窄终端通过顶部页签切换列，缩放后按当前可见窗口处理点击。

`sai config`（及 `/config`）支持仪表盘入口、列表项、多步表单字段、压缩阈值卡片及底部操作按钮的鼠标点击、滚轮滚动与悬停高亮。

`/ps` 后台任务管理器支持列表选择、过滤标签切换、命令详情区点击展开或收起完整命令，以及日志视口滚轮浏览。全屏视图中点击“回到底部 / 有新输出”胶囊按钮时，在跳回底部的同时自动收起可视区外的工具详情，仅保留底部可见区域内的已展开项。

`/thinking`、`/agent`、`/tree` 共用的过滤列表支持点击选择、悬停反馈、滚轮移动、确认和取消。`/resume` 支持选择会话、滚轮移动、恢复、取消和切换工作区范围。`/context` 查看面板支持滚轮浏览和点击关闭。提问卡片与权限审批提示同样支持鼠标点击选择。键盘输入过滤及原有快捷键继续可用。

模型运行期间，底栏操作遵循斜杠命令现有策略：模型和思考选择显示当前不可用提示，上下文查询输出统计，权限模式可即时切换，不打开阻塞执行的选择器。

内联界面开启鼠标捕获后，终端原生文字选择和滚动通常需按住 `Shift` 再拖动或滚轮操作；具体按键遵循终端设置。`PageUp` 可打开会话浏览器，`Ctrl+O` 可切换全屏浏览。输入框与底栏拖选由 TUI 处理，无需按住修饰键。
